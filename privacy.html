Website privacy

A deliberately quiet website.

Martinez Studio does not add analytics, advertising scripts, accounts, forms, or cookies to this website.

What the site processes

The site consists of static files hosted through GitHub Pages. Like other web hosts, GitHub may process ordinary request information needed to deliver pages, such as IP address, browser details, requested URLs, and timestamps. GitHub controls that hosting infrastructure under its own privacy terms.

External links

Links to GitHub and other future distribution platforms take you to services with their own privacy practices. No information is intentionally passed beyond the destination URL.

App privacy

Each released Martinez Studio app will provide product-specific privacy information on its own page. An app’s behavior is separate from this website.

Changes

This page was last updated September 1, 2026. It will be revised if the website begins using analytics, forms, accounts, or another data-processing service.
